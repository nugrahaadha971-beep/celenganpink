# Celengan Kekayaan (tema pink) — pasang di iPhone

Aplikasi ini PWA: dipasang dari Safari, tampil layar penuh seperti aplikasi biasa, dan jalan offline.

1. Unggah semua isi folder ini ke GitHub Pages (atau hosting HTTPS lain). Safari butuh HTTPS.
2. Buka alamat situsnya di **Safari** di iPhone (harus Safari, bukan Chrome).
3. Ketuk tombol **Bagikan** (kotak dengan panah ke atas) → **Tambah ke Layar Utama** → **Tambah**.
4. Buka dari ikon di layar utama. Splash dan ikon buaya pink akan muncul.

Catatan:
- Data tersimpan di perangkat. Pakai menu Cadangkan secara berkala.
- Setelah memperbarui file di hosting, tutup aplikasi lalu buka lagi (kadang dua kali) agar versi baru dimuat.
- Aplikasi native (.ipa / App Store) butuh Mac dengan Xcode dan akun Apple Developer, tidak bisa dibuat dari sini.
